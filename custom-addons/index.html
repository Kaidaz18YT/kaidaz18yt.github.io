FAQ

 

Which editions can you make addons and mods for?

Bedrock (Windows, mobile, console, Realms and Bedrock servers) using behaviour packs and the Script API; Education Edition using the same kind of addon, delivered as a world or template; and Java Edition as Paper/Spigot plugins or Fabric/Forge mods. Tell me your Minecraft version so I build for the right one.

Why is it code only? Can I get custom art?

I focus on scripting, so addons use vanilla items, blocks and mobs, plus at most a few simple textures when the code needs them. No custom models or animations. If you have your own textures or models, send them and I'll hook them up.

Does it work on Education Edition?

Usually, yes. Education Edition runs addons from inside a world, so I send it as a .mcworld or template. It is often a version or two behind regular Bedrock, so some newer scripting features may not be available. I'll tell you before you pay if something can't be done there.

What if it breaks after a Minecraft update?

If it breaks within a few days because of a mistake I made, I'll fix it free. Updating it for a new Minecraft version later is an "Addon or mod changes" job ($10–$20).

Need a server set up instead?

That's a separate service. See Minecraft server setup & fixes.
