Upload several videos, then drag the trim handle on one reference clip to mark where its ending should be cut. That same cut length is removed from the end of every other video. Output is .mp4. Works in Chrome and Edge.

Processing happens entirely in your browser — nothing is uploaded anywhere. Each video is decoded and re-encoded frame-by-frame (not played back live) so the output isn't affected by playback stutter, then combined with the original audio and packaged as .mp4. Requires Chrome or Edge (uses the WebCodecs API, which Firefox and Safari don't support).
