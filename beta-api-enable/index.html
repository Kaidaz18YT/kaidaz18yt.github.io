How it works

Four steps, about a minute.
  1. Export your world. In Minecraft, edit the world, scroll to the bottom of settings and choose Export World. Save the .mcworld file.
  2. Drop it in above. The site reads the world's level.dat and shows which experiments are already on.
  3. Enable and download. You get a new file called yourworld-beta-apis.mcworld.
  4. Open it. Double-click the new file to import it into Minecraft. It appears as a separate world next to your original.

What are Beta APIs?

A quick explanation before you switch them on.

Beta APIs are the experimental scripting modules in Minecraft Bedrock and Education Edition. Turning them on lets a behaviour pack use modules like @minecraft/server in their beta form, which is how a lot of modern scripted add-ons work.

Historically you had to recreate the world with the right experiments ticked, or dig through the world's files by hand. This enabler writes the same flags Minecraft's own settings write, so an existing world keeps its terrain, players and builds.

Use it when an add-on, tutorial or map says it "requires Beta APIs", or when you are following a Kaidaz18 install video that starts with "enable experiments". If you only want a picture to share, the join code maker is the other tool worth a look.

Good to know

The questions people ask before switching experiments on.
Is my world uploaded anywhere?

No. The world file is opened, edited and re-packed locally in your browser. There is no server and no upload, so the world never leaves your device.

Will enabling Beta APIs turn off achievements?

Yes. Minecraft disables achievements in any world that has experiments enabled. That is a game rule, not something this site adds.

Do I still need a beta version of my add-on?

Yes. The world toggle only permits beta modules. The behaviour pack's manifest must also depend on a beta version of @minecraft/server.

Does it work with Minecraft Java Edition worlds?

No. Beta APIs are a Bedrock and Education Edition feature, and the tool will tell you if it sees a Java world.

Does the original world file get changed?

No. Only level.dat inside the downloaded copy is edited — the gametest flag plus the two bookkeeping flags Minecraft expects, and every other byte is left as it was. Your original .mcworld stays exactly as it was, and the new file is imported as a separate world.
