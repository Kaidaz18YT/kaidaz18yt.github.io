How it works

Four steps, about a minute.
  1. Export your world. In Minecraft, edit the world, scroll to the bottom of settings and choose Export World. Save the .mcworld file.
  2. Drop it in above. The site reads the world's level.dat and shows which experiments are already on.
  3. Enable and download. You get a new file called yourworld-beta-apis.mcworld.
  4. Open it. Double-click the new file to import it into Minecraft. It appears as a separate world next to your original.

Good to know

Your world stays private. The file is opened, edited and re-packed locally in your browser. There is no server and no upload.

Achievements turn off. Minecraft disables achievements in any world that has experiments enabled. That is a game rule, not something this site adds.

Your add-on still needs a beta version. The world toggle only permits beta modules. The behavior pack's manifest must also depend on a beta version of @minecraft/server.

Bedrock only. Java worlds don't have Beta APIs, and the site will tell you if it sees one.
